# 1. Understanding Client and Server

**Goal:** Understand the basic client-server model.

A weather application allows a user to enter a city.

The application sends a request to a remote server.

The server processes the request and sends information about the weather back to the application.

Answer the following questions.

1. What is the client?

2. What is the server?

3. What information does the client send?

4. What does the server send back?

5. Why does the client need to communicate with the server?

6. What would happen if the server could not be reached?

7. Give two other examples of client-server communication that you use in everyday life.

* Folder: `teh-software-engineering/module-7`

* File: `1-understanding-client-server.md`

* Answer all questions in your own words.

* Draw a simple client → server → response diagram.

Do not search for a definition and copy it. The goal is to explain the idea in a way you understand.
