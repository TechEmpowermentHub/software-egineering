# 7. First API Request

**Goal:** Make your first HTTP request from Python.

Use a public API that does not require authentication.

Your instructor will provide the API endpoint to use in class.

Write a Python program that:

1. Sends a GET request to the endpoint.

2. Receives the response.

3. Prints the HTTP status code.

4. Prints the response body.

Before running the program, answer:

1. What URL are you requesting?

2. What HTTP method are you using?

3. What do you expect the server to return?

4. What status code would indicate success?

After running the program, compare your expectations with the actual response.

**## Requirements**

* Folder: `teh-software-engineering/module-7`

* File: `7-first-api-request.py`

* Use Python's `requests` library.

* Make a GET request.

* Print the status code.

* Print the response.

Do not copy an API request without understanding what the URL and response represent.
