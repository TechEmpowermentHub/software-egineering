# 2. Reading a URL

**Goal:** Understand the basic components of a URL.

Consider the following URL:

```text
https://example.com/products?category=phones&page=2
```

Identify:

1. The protocol.

2. The domain.

3. The path.

4. The first query parameter.

5. The second query parameter.

6. The value of `category`.

7. The value of `page`.

Now consider:

```text
https://api.example.com/users/25
```

Identify:

1. The protocol.

2. The domain.

3. The path.

4. The resource being requested.

5. The value `25`.
