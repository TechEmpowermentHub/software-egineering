# Exercises

The exercises progressively introduce the capabilities required for this module's project.

```text
Internet communication

        ↓

Client / Server

        ↓

URLs

        ↓

HTTP

        ↓

Requests / Responses

        ↓

Status codes

        ↓

JSON

        ↓

API

        ↓

Making API requests

        ↓

Processing API data

        ↓

Handling errors

        ↓

Problem solving

        ↓

PROJECT
```

Complete the exercises in that order.

The goal is not simply to make an API request successfully.

You should understand:

* what program is making the request
* where the request is going
* what information is being sent
* what the server returns
* how the response is structured
* how the program processes the response

By the end of the exercises, you should be able to write a Python program that communicates with an external service and uses the returned data to solve a problem.
