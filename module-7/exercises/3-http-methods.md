# 3. HTTP Methods

**Goal:** Understand why HTTP requests use different methods.

For each situation below, identify the HTTP method that would normally be appropriate.

Use:

```text
GET
POST
PUT
PATCH
DELETE
```

### Situation 1

A user wants to retrieve their profile.

### Situation 2

A user creates a new account.

### Situation 3

A user changes their email address.

### Situation 4

An administrator completely replaces the information for a product.

### Situation 5

An administrator removes a product.

### Situation 6

A program retrieves a list of customers.

### Situation 7

A program creates a new order.

### Situation 8

A program changes only the delivery address of an existing order.

For each answer, explain **why** you selected that method.

**## Requirements**

* Folder: `teh-software-engineering/module-7`

* File: `3-http-methods.md`

* Answer all eight situations.

* Explain the reasoning behind each answer.

Do not simply memorize the method names. Think about what the program is trying to do.
