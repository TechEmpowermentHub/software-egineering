# 9. API Query Parameters

**Goal:** Send user-provided information to an API.

Use an API that supports query parameters.

Write a program that asks the user for some information and uses that information to make an API request.

For example:

```text
Enter a search term: python
```

The program should use the user's input as a query parameter.

The program should then display relevant results from the API.

**## Requirements**

* Folder: `teh-software-engineering/module-7`

* File: `9-api-query.py`

* Ask the user for input.

* Use the input in an API request.

* Use query parameters.

* Process the JSON response.

* Display useful results.

* Test the program with different inputs.

Before writing the code, identify:

**Input**

What does the user provide?

**Request**

What API endpoint is being called?

**Parameter**

How does the user's input affect the request?

**Response**

What data does the API return?

**Output**

What information should the user see?
