# 11. Solving a Real Problem

**Goal:** Combine APIs, user input, conditions, loops, functions, and data processing to solve a practical problem.

Imagine that a user wants to look up information from an external service.

Your program should allow the user to:

1. Enter a search or query.

2. Send the query to an API.

3. Receive the response.

4. Check whether the request succeeded.

5. Extract useful information.

6. Display the results.

7. Perform another search if the user wants to continue.

For example:

```text
Enter search: python

Results:
...

Search again? yes

Enter search: programming

Results:
...

Search again? no

Goodbye.
```

The exact API will be provided by the instructor.

Before writing Python, identify:

**Input**

What information does the user provide?

**Processing**

What does the program need to do with the input?

**API Request**

What endpoint will be called?

**Parameters**

What information must be sent to the API?

**Response**

What information does the API return?

**Output**

What should the user see?

**Repetition**

What should happen repeatedly?

**Errors**

What can go wrong?

**Algorithm**

Write the solution in plain English or pseudocode.

Only after completing this analysis should you begin writing the Python program.
