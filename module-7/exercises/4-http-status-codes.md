# 4. HTTP Status Codes

**Goal:** Understand what HTTP response status codes tell a program.

Match each situation with an appropriate status code.

Use:

```text
200
201
400
401
403
404
500
```

### Situation 1

A request was successful and the server returned the requested data.

### Situation 2

A new resource was successfully created.

### Situation 3

The request contains invalid information.

### Situation 4

The user has not provided valid authentication credentials.

### Situation 5

The user is authenticated but is not allowed to perform the operation.

### Situation 6

The requested resource does not exist.

### Situation 7

The server encountered an unexpected error.

After completing the exercise, answer:

1. Why is a status code useful to a program?

2. Why shouldn't a program assume every request succeeds?

3. What should a program do when it receives an unsuccessful status code?
