# Assessment

You will be assessed on your ability to:

* Explain the basic client-server model.
* Identify the components of a URL.
* Explain the purpose of HTTP.
* Identify common HTTP methods.
* Explain the basic structure of an HTTP request and response.
* Interpret common HTTP status codes.
* Read and understand JSON data.
* Work with dictionaries and lists containing JSON data.
* Make an HTTP request from Python.
* Process data returned by an API.
* Use query parameters.
* Handle unsuccessful API requests.
* Read API documentation.
* Break an API-based problem into computational steps.
* Produce readable code.
* Explain your solution.

The final assessment will involve solving a new problem that requires communication with an external API rather than simply reproducing the module project.

The assessment will test whether you can recognize:

* what information the program needs
* what API endpoint is required
* what parameters need to be sent
* what information the API returns
* how to extract the required data
* how to handle unsuccessful requests
* how to turn the returned data into useful output

You should be able to explain the complete flow:

```text
User Input
    ↓
Program
    ↓
HTTP Request
    ↓
API
    ↓
HTTP Response
    ↓
JSON
    ↓
Python Data
    ↓
Processing
    ↓
Useful Output
```

The assessment is not primarily testing whether you remember the syntax of a particular API library.

It is testing whether you understand how applications communicate and whether you can use that communication to solve a problem.
