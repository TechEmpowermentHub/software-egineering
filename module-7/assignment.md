# Assignment

Complete all exercises independently and submit the **API Information Explorer** project.

Your submission should contain:

```text
module-7/

├── exercises/

│   ├── 1-understanding-client-server.md

│   ├── 2-reading-a-url.md

│   ├── 3-http-methods.md

│   ├── ...

│   └── 11-solving-a-real-problem.py

└── project/

    ├── api-information-explorer.py

    └── README.md
```

Your project README should contain:

1. What the program does
2. The API you used
3. A link to the API documentation
4. How to run the program
5. Example input
6. Example output
7. The API endpoint used
8. The HTTP method used
9. The parameters used
10. The inputs
11. The processing
12. The outputs
13. The algorithm/pseudocode
14. A brief explanation of the JSON response
15. A brief explanation of how errors are handled
16. A brief explanation of the main functions in the program

The project should be committed to Git and pushed to the student's GitHub repository.

Students should be prepared to demonstrate the project and explain how the program communicates with the API.
