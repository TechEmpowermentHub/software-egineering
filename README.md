```text
A 3-month software engineering foundation program, followed by specialization tracks.
```

## About the Course

Intro to Computer programming and Software Engineering is a free, practical, 12 weeks course for people who want to learn how to program computers and maintain such programs, and everything in-between

This course follows a complete path from having an idea in your head, designing a solution for it, and implementing and running that solution in a computer/phone so other people can use it

```text
Have idea in your head, design a solution, implement the solution, deploy solution so users can use it
```

You will understand how computers work, learn to write Python programming language, Work with the terminal, and the Git/GitHub

This is not a theory-only course. The emphasis is on building usesful programs

## Who should join

This course is for you if you:
- Have no prior background in computer programming
- Want a structured introduction to Computer programming and Software Engineering
- Want to understand how computer programs and softwares are constructed
- Learn best by completing homeworks and building end-to-end projects
- Want portfolio portfolio projects that demonstrate practical knowledge
- Benefit from cohort deadlines, community support, peer review

## Prerequisites

This course has no prerequisites

However, you are expected to have:
- A computer
- Internet connection

Helpful but not required
- Familiarity with how computers work
- Familiarity with python
- Familiarity with command line
- Basic Git and GitHub experience

## Automated Checks

Your submission will be automatically checked for:

- Required files
- Program execution
- Expected output
- Input handling
- Arithmetic correctness
- Project functionality

**NOTE:** Automated checks verify functional requirements. They do not replace
human review of your code, documentation, or understanding.
