# Project - Personal Expense Calculator

The exercises in this module have progressively introduced the capabilities required for this project.

You will now combine them into a single program.

**Problem**

Build a command-line program that calculates how much money a person has left after their expenses.

The program should ask the user for:

- monthly income
- rent
- food expenses
- transportation expenses
- internet/data expenses
- other expenses

It should then calculate:

Total expenses
Remaining money

**Example**

Monthly income: 200000
Rent: 50000
Food: 40000
Transportation: 20000
Internet/Data: 10000
Other expenses: 15000

------------------------------
Total expenses: 135000
Remaining money: 65000
------------------------------

**Before You Code**

Write down:

**Inputs**

What information does the program need?

**Processing**

What calculations need to happen?

**Outputs**

What information should the program display?

**Algorithm**

Write the steps of the solution in plain English or pseudocode.

Only after doing this should you begin writing the Python program.

**Bonus**
After displaying their expenses and money left, also display:

- each expense as a percentate of monthly income
- total percentage spent
- total percentage left
