# Assessment

You will be assessed on your ability to:

- Write and run Python programs.
- Use variables correctly.
- Receive and process user input.
- Perform calculations correctly.
- Convert data types when necessary.
- Break a problem into inputs, processing, and outputs.
- Produce readable code.
- Explain your solution.

The final assessment will involve solving a new problem that uses the same fundamental concepts, rather than simply reproducing the project.
