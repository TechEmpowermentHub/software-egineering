# Module 1 - Introduction to Programming and Problem Solving

## What are we doing this week
The purpose of week 1 is to get students to understand what a program is, how a computer executes instructions, and how to turn a simple problem into a working program.

## Objectives

By the end of the week, students should be able to:

1. Explain what a program is and how it runs. 
2. Work with the terminal and basic files/folders. 
3. Write and execute a basic Python program. 
4. Use variables to represent information. 
5. Work with basic data types and expressions. 
6. Read input and produce output. 
7. Break a simple real-world problem into computational steps.

## Concepts

1. Computing: 
    - computer vs program
    - source code
    - programming language
    - interpreter
    - files/folders
    - terminal
2. Python
    - print()
    - comments
    - variables
    - naming
    - strings
    - integers
    - floats
    - booleans
    - arithmetic operators
    - comparison operators
    - input()
    - type conversion (int()
    - float(), str())
    - basic expressions. Problem solving: inputs → processing → outputs
    - algorithms
    - pseudocode
    - breaking problems into steps.

## Activities

1. Environment Setup
    - Install VS Code
    - Install Python
    - Install Git
    - Configure Git
    - Create GitHub account
    - Install/configure necessary VS Code extensions
    - Verify everything works
2. Computer & Programming Orientation
    - Understand files and folders
    - Open the terminal
    - Navigate directories
    - Create/delete/move files from the terminal
    - Run a Python program
3. Guided Programming Exercises
    - print()
    - variables
    - strings
    - numbers
    - arithmetic
    - user input
    - type conversion
4. Problem-Solving Exercise
    - Take a real-world problem
    - Identify inputs
    - Identify processing
    - Identify outputs
    - Write the steps in plain English/pseudocode
    - Translate those steps into Python
5. Project Workshop
    - Design the expense calculator
    - Implement it
    - Test it with different inputs
    - Debug problems
    - Commit the project to Git
6. Code Review
    - Students demonstrate their programs
    - Discuss different solutions
    - Review code quality
    - Identify bugs and improvements

## Exercises

Do the exercises in the [Exercises folder](./exercises/) in order, after which you are fully equipped to do this module's project

## Project

Personal Expense Calculator — Build a command-line program that asks the user for their available money and several expenses, calculates the total spent and remaining balance, and displays a simple summary. Students should first describe the algorithm before writing code.
