# Assessment

You will be assessed on your ability to:

* Define and call functions correctly.
* Use parameters appropriately.
* Use return values appropriately.
* Explain the difference between `print()` and `return`.
* Understand basic variable scope.
* Create and manipulate lists.
* Loop through collections.
* Create and manipulate dictionaries.
* Combine functions and collections.
* Break a larger problem into smaller functions.
* Give functions clear responsibilities.
* Use conditionals and loops within a larger program.
* Produce readable and organized code.
* Explain how your program works.

The final assessment will involve solving a new problem that uses the same fundamental concepts rather than simply reproducing the Student Management System.

The assessment will test whether you can take a problem, identify the data it requires, identify the operations it needs, break those operations into functions, and choose appropriate collections for storing the data.
