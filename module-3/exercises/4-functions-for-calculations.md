# 4. Functions for Calculations

**Goal:** Use functions to separate different responsibilities.

Write three functions:

```python
calculate_area()
calculate_perimeter()
describe_rectangle()
```

The first function should calculate and return the area of a rectangle.

The second should calculate and return the perimeter.

The third should display a summary using the results.

For example:

```text
Length: 10
Width: 5
Area: 50
Perimeter: 30
```

## Requirements

* File: 4-functions-for-calculations.py
* Use parameters.
* Use return values.
* Each function should have a clear responsibility.
* Do not place all calculations inside one large function.
