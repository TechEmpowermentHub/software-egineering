# 6. Working with Lists

**Goal:** Store and manipulate multiple values.

Create a list containing five people's names.

Your program should:

* Print the entire list.
* Print the first name.
* Print the last name.
* Add another name.
* Remove one name.
* Print the updated list.

## Requirements

* File: 6-working-with-lists.py
* Create a list.
* Access items using indexes.
* Add an item.
* Remove an item.
* Print the updated list.
