# Exercises

The exercises progressively introduce the capabilities required for this module's project.

```text
Functions
   ↓
Parameters
   ↓
Return values
   ↓
Scope
   ↓
Lists
   ↓
Looping through lists
   ↓
Dictionaries
   ↓
Functions + collections
   ↓
Program decomposition
   ↓
PROJECT
```

Complete the exercises in order.

The goal is not simply to make the program produce the correct output. You should understand what each function is responsible for, what information it receives, and what information it produces.
