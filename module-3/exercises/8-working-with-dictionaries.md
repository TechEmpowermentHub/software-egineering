# 8. Working with Dictionaries

**Goal:** Use dictionaries to represent structured information.

Create a dictionary representing a student.

The student should have:

```
name
age
city
```

For example:

```python
student = {
    "name": "Kelechi",
    "age": 20,
    "city": "Abakaliki"
}
```

Your program should:

* Print the student's name.
* Print the student's age.
* Print the student's city.
* Change the student's city.
* Add the student's score.
* Print the updated information.

## Requirements
* File: 8-working-with-dictionaries.py
* Create a dictionary.
* Access values using keys.
* Modify a value.
* Add a new key-value pair.
* Print the updated dictionary.
