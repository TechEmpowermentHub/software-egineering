# 7. Processing a List

**Goal:** Use a loop to process multiple values stored in a list.

Create a list containing several numbers.

Write a program that calculates and displays:

```
The total
The number of values
The average
```

For example:

```
Numbers: 10, 20, 30, 40, 50
Total: 150
Count: 5
Average: 30
```

## Requirements

* File: 7-processing-a-list.py
* Store the numbers in a list.
* Use a loop to process the values.
* Calculate the total.
* Calculate the count.
* Calculate the average.
* Do not manually add each number.
