# 3. Returning a Value

**Goal:** Understand the difference between printing and returning a value.

Write a function called `add_numbers()` that accepts two numbers and returns their sum.

For example:

`result = add_numbers(10, 20)`

should cause result to contain:

`30`

Then print the result.

## Requirements

* File: 3-returning-a-value.py
* Define a function named `add_numbers()`.
* Accept two parameters.
* Return the sum.
* Store the returned value in a variable.
* Print the result.

Do not print the result directly from `inside add_numbers()`.
