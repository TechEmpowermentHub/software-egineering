# 2. Functions with Parameters

**Goal:** Pass information into a function.

Write a function called greet_user() that accepts a person's name as a parameter.

The function should display:

`Hello, Kelechi!`

when called with:

`greet_user("Kelechi")`

Your program should also call the function with at least two other names.

## Requirements

* File: 2-functions-with-parameters.py
* Define a function with one parameter.
* Pass different values to the function.
* Use the parameter inside the function.
* Do not hard-code each person's name inside the function.
