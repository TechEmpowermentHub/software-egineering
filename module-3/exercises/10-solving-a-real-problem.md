# 10. Solving a Real Problem

**Goal:** Break a larger problem into functions and data structures.

A small school wants a simple program for managing students.

The program needs to store information about several students.

For each student, store:

```text
* Name
* Age
* Score
```

The program should be able to:

```text
* Add a student
* Display all students
* Find a student by name
* Calculate the average score
```

Before writing Python code, identify:

### Data

What information needs to be stored?

How should that information be represented?

### Functions

What tasks does the program need to perform?

Which tasks should become functions?

### Inputs

What information does the program receive?

### Processing

What calculations and operations need to happen?

### Outputs

What information should the program display?

### Algorithm

Write the steps of the solution in plain English or pseudocode.

### Program Structure

Sketch the major functions your program will need.

Only after completing this planning should you begin writing the Python program.

## Requirements

* File: 10-solving-a-real-problem.py
* Use functions.
* Use at least one list.
* Use dictionaries to represent students.
* Use loops.
* Use conditional statements.
* Use return values where appropriate.
* Keep functions focused on specific responsibilities.
* Test the program with multiple students.
