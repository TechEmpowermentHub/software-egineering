# 1. Your First Function

**Goal:** Define and call a function.

Write a program containing a function called `greet()`.

The function should print:

`Hello, welcome to the program!`

Call the function so that the message appears when the program runs.

## Requirements

* Folder: teh-software-engineering/module-3
* File: 1-your-first-function.py
* Define a function named greet().
* Call the function.
* The function should contain the print() statement.
