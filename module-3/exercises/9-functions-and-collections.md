# 9. Functions + Collections

**Goal:** Combine functions, lists, and dictionaries.

Create a program that stores several students.

Each student should have:

```text
name
age
score
```

For example:

```python
students = [
    {"name": "Kelechi", "age": 20, "score": 75},
    {"name": "Adekunle", "age": 19, "score": 82},
    {"name": "Hassan", "age": 21, "score": 68}
]
```

Write functions that:

* Display all students.
* Find a student by name.
* Calculate the average score.

## Requirements

* File: 9-functions-and-collections.py
* Use a list.
* Use dictionaries.
* Use functions.
* Use loops.
* Use conditional statements.
* Return values from functions where appropriate.

The important part of this exercise is deciding which function should be responsible for which task.
