# Assignment

Complete all exercises independently and submit the Student Management System.

Your submission should contain:

```text
module-3/

├── exercises/

│   ├── 1-your-first-function.py
│   ├── 2-functions-with-parameters.py
│   ├── 3-returning-a-value.py
│   └── ...

└── project/

    ├── student-management.py
    └── README.md
```

Your project README should contain:

1. What the program does
2. How to run it
3. Example input
4. Example output
5. The data the program stores
6. The functions used by the program
7. The responsibility of each major function
8. The algorithm/pseudocode
9. A brief explanation of how students are represented and stored
