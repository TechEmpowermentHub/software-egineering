# Assessment

You will be assessed on your ability to:

* Create and import Python modules.
* Organize code across multiple files.
* Read information from files.
* Write information to files.
* Work with JSON data.
* Work with CSV data.
* Understand exceptions.
* Handle expected errors using `try` and `except`.
* Validate user input.
* Combine functions, collections, files, and error handling.
* Design a program that persists information between executions.
* Give modules and functions clear responsibilities.
* Produce readable and organized code.
* Explain how your program works.

The final assessment will involve solving a new problem that uses the same fundamental concepts rather than simply reproducing the Student Management System.

The assessment will test whether you can:

1. Identify what information a program needs to persist.
2. Choose an appropriate representation for that information.
3. Organize the program into logical modules.
4. Read and write persistent data.
5. Handle expected errors.
6. Break the problem into functions.
7. Explain the design and implementation of your solution.
