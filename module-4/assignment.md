# Assignment

Complete all exercises independently and submit the Persistent Student Management System.

Your submission should contain:

```text
module-4/

├── exercises/

│   ├── 1-creating-a-module/
│   ├── 2-importing-functions.py
│   ├── 3-reading-a-file.py
│   └── ...

└── project/

    ├── main.py
    ├── student_manager.py
    ├── storage.py
    ├── students.json
    └── README.md
```

Your exact project structure may differ as long as the program is logically organized.

Your project README should contain:

1. What the program does
2. How to run it
3. Example input
4. Example output
5. What data the program stores
6. How the data is stored
7. What files/modules the program contains
8. The responsibility of each major module
9. The responsibility of each major function
10. How errors are handled
11. The algorithm/pseudocode
