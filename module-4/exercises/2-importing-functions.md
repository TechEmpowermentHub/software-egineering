# 2 - Importing Functions

**Goal:** Use a module containing several functions.

Create a module called `calculator.py`.

It should contain functions for:

```text
addition
subtraction
multiplication
division
```

Create another file called `main.py`.

Import the functions from `calculator.py` and use them with numbers entered by the user.

Example:

```text
Enter first number: 20
Enter second number: 5

Sum: 25
Difference: 15
Product: 100
Quotient: 4
```

## Requirements
* File: `2-importing-functions/main.py`, `2-importing-functions/calculator.py`
* Create a separate module.
* Define multiple functions in the module.
* Import the functions into another file.
* Use user input.
* Use the returned values from the functions.
