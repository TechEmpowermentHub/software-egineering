# 8 — Handling Invalid Input

**Goal:** Handle invalid user input.

Write a program that asks the user to enter their age.

The program should convert the input to an integer.

If the user enters something that is not a number, the program should not crash.

For example:

```text
Enter your age: twenty

Please enter a valid number.

```

If the user enters a valid age:

```text
Enter your age: 20

Your age is 20.
```

## Requirements
* File: 8-handling-invalid-input.py
* Use input().
* Convert the input to an integer.
* Use try and except.
* Handle invalid input.
* Test the program with both valid and invalid values.
