# 1 - Creating a Module

**Goal:** Understand how code can be separated into different Python files.

Create two Python files:

```text
greetings.py
main.py
```

In `greetings.py`, create a function called `greet()` that prints:

```text
Hello, welcome to the program!
```

In `main.py`, import the function and call it.

## Requirements
* File: `1-creating-a-module/main.py`, `1-creating-a-module/greetings.py`
* Create a separate module containing the function.
* Import the function into main.py.
* Call the function from main.py.
* Run main.py from the terminal.

The important idea is that the function is defined in one file and used from another file.
