# Exercises

The exercises progressively introduce the capabilities required for this module's project.

```text
Modules
   ↓
Imports
   ↓
Reading files
   ↓
Writing files
   ↓
JSON
   ↓
CSV
   ↓
Exceptions
   ↓
Error handling
   ↓
Combining files + functions + errors
   ↓
Persistent data
   ↓
PROJECT
```

Complete the exercises in order.

The goal is not simply to learn how to open and save files. Students should understand why programs need persistent data, how different files can be used to organize software, and how programs can handle situations where something goes wrong.
