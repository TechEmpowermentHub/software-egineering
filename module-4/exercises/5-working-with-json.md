# 5 — Working with JSON

**Goal:** Store structured data using JSON.

Create a program that stores information about a student:

```text
name
age
city
score
```

Save the student information to a JSON file.

The resulting JSON should represent the student's information in a structured way.

Then modify the program so that it reads the JSON file and displays the student's information.

## Requirements
* File: 5-working-with-json.py
* Create a Python dictionary.
* Write the dictionary to a JSON file.
* Read the JSON file.
* Convert the JSON data back into Python data.
* Display the student's information.
* Use Python's json module.
