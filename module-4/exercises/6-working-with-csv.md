# 6 — Working with CSV

**Goal:** Work with tabular data stored in a CSV file.

Create a CSV file containing several students.

The CSV should contain:

```text
name,age,score
Kelechi,20,75
Ada,19,82
Emeka,21,68
```

Write a Python program that reads the CSV file and displays each student's information.

Then calculate and display the average score.

## Requirements
* File: 6-working-with-csv.py
* Create a CSV file.
* Read the CSV using Python.
* Process multiple rows.
* Display the students.
* Calculate the average score.
* Use Python's csv module.
