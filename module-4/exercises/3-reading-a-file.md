# 3 Reading a Text File

**Goal:** Read information stored in a file.

Create a text file containing several lines of text.

For example:

```text
Kelechi
Ada
Emeka
Chinedu
```

Write a Python program that opens the file and prints its contents.

Then modify the program so that each line is printed separately.

## Requirements
* File: 3-reading-a-file.py
* Create a text file containing information.
* Open the file using Python.
* Read its contents.
* Display the contents.
* Close the file appropriately.

Use Python's with open(...) pattern.
