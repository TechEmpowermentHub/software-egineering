# 4 — Writing to a File

**Goal:** Save program output to a file.

Write a program that asks the user for:

```text
name
age
city
```

The program should save the information to a text file.

For example, the file should contain:

```text
Name: Kelechi
Age: 20
City: Port Harcourt
```

Run the program with different information and inspect the file afterward.

## Requirements
* File: 4-writing-to-a-file.py
* Ask the user for information.
* Open a file for writing.
* Write the information to the file.
* Close the file appropriately.
* Verify that the information was saved.
