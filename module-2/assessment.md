# Assessment

You will be assessed on your ability to:

* Use Boolean expressions correctly.
* Compare values.
* Make decisions using `if`, `elif`, and `else`.
* Combine conditions using logical operators.
* Use `for` loops to repeat actions.
* Use `while` loops to repeat actions based on a condition.
* Trace the execution of a program.
* Identify and fix logical errors.
* Break a problem involving decisions and repetition into computational steps.
* Produce readable code.
* Explain your solution.

The final assessment will involve solving a new problem that uses the same fundamental concepts rather than simply reproducing the ATM Simulator.

The assessment will test whether you can recognize **when a problem requires a decision, when it requires repetition, and how to translate those requirements into program logic**.
