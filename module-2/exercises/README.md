# Exercises

The exercises progressively introduce the capabilities required for this module's project.

```text
Boolean values
      ↓
Comparisons
      ↓
if
      ↓
if / else
      ↓
elif
      ↓
and / or / not
      ↓
for loops
      ↓
while loops
      ↓
Decisions + repetition
      ↓
Problem solving
      ↓
PROJECT
```

Complete the exercises in that order.

The goal is not simply to get the correct output. You should understand **why the program behaves the way it does.**

By the end of the exercises, you should be able to write programs that make decisions and repeat actions based on conditions.
