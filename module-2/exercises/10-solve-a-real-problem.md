# 10. Solving a Real Problem

**Goal:** Combine decisions and repetition to solve a small real-world problem.

A shop wants a simple program that calculates the total cost of purchases.

The program should repeatedly ask the user for the price of an item.

After each item, the program should ask whether they want to enter another item.

If they answer `yes`, the program should ask for another price.

If they answer `no`, the program should stop and display the total amount.

**Example**

```text
Enter item price: 2500
Add another item? yes

Enter item price: 1500
Add another item? yes

Enter item price: 3000
Add another item? no

Total: 7000
```

Before writing the Python code, identify:

**Input:**

What information does the program need?

**Processing:**

What calculations and decisions need to happen?

**Output:**

What information should the program display?

**Repetition:**

What part of the program needs to happen repeatedly?

**Algorithm:**

Write the steps of the solution in plain English or pseudocode.

Only after doing this should you begin writing the Python program.

* Folder: `teh-software-engineering/module-2`

* Use a `while` loop.

* Keep track of the running total.
* Display the final total.
