# 1. Boolean Expressions

**Goal:** Understand Boolean values and expressions.

Write a program that creates several Boolean expressions and prints their results.

Use comparisons such as:

* Is 10 greater than 5?
* Is 10 equal to 10?
* Is 7 less than 3?
* Is 15 not equal to 20?

**Example Output**

```text
True
True
False
True
```

## Requirements

* Folder: `teh-software-engineering/module-2`
* File: `1-boolean-expressions.py`
* Use comparison operators.
* Print the result of each Boolean expression.
* Test your program with different values.

Before running the program, try to predict the result of each expression.
