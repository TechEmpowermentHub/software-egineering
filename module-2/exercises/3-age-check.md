# 3. Age Check

**Goal:** Use `if` and `else` to choose between two outcomes.

Write a program that asks the user for their age.

If the user is 18 or older, display:

```text
You are an adult.
```

Otherwise, display:

```text
You are under 18.
```

**Example**

```text
Enter your age: 20

You are an adult.
```

## Requirements

* Folder: `teh-software-engineering/module-2`
* File: `3-age-check.py`
* Ask the user for their age.
* Convert the input to an integer.
* Use `if` and `else`.
* Test the program with ages below and above 18.
