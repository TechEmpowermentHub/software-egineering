# 4. Grade Classifier

**Goal:** Use `if`, `elif`, and `else` to handle multiple possible outcomes.

Write a program that asks the user for a student's score.

Classify the score using the following rules:

```text
70 - 100    → A
60 - 69     → B
50 - 59     → C
45 - 49     → D
40 - 44     → E
0 - 39      → F
```

Display the appropriate grade.

**Example**

```text
Enter your score: 73

Grade: A
```

## Requirements

* Folder: `teh-software-engineering/module-2`
* File: `4-grade-classifier.py`
* Ask the user for a score.
* Convert the input to an integer.
* Use `if`, `elif`, and `else`.
* Test several different scores.
* Think about what should happen if a user enters a score below 0 or above 100.
