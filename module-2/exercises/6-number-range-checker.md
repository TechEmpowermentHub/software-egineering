# 6. Number Range Checker

**Goal:** Use logical operators to combine conditions.

Write a program that asks the user for a number.

The program should determine whether the number is between 10 and 20, inclusive.

If it is within the range, display:

```text
The number is between 10 and 20.
```

Otherwise, display:

```text
The number is outside the range.
```

**Example**

```text
Enter a number: 15

The number is between 10 and 20.
```

## Requirements

* Folder: `teh-software-engineering/module-2`
* File: `6-number-range-checker.py`
* Ask the user for a number.
* Use a Boolean expression.
* Use `and`.
* Include both boundaries.
* Test numbers below, inside, and above the range.
