# 5. Login Check

**Goal:** Combine multiple conditions using `and`.

Write a program that asks the user for:

* username
* password

The program should allow access only when both values are correct.

Use:

```text
username: admin
password: 1234
```

If both are correct, display:

```text
Login successful.
```

Otherwise, display:

```text
Invalid username or password.
```

**Example**

```text
Username: admin
Password: 1234

Login successful.
```

## Requirements

* Folder: `teh-software-engineering/module-2`
* File: `5-login-check.py`
* Ask for both username and password.
* Use a Boolean condition.
* Use `and`.
* Test the program with correct and incorrect credentials.
