# 8. Repeated Input with a `while` Loop

**Goal:** Use a `while` loop to repeat an action until a condition changes.

Write a program that repeatedly asks the user to enter a password.

The correct password is:

```text
python123
```

The program should continue asking until the user enters the correct password.

When the correct password is entered, display:

```text
Access granted.
```

**Example**

```text
Enter password: hello
Incorrect password.

Enter password: abc
Incorrect password.

Enter password: python123
Access granted.
```

## Requirements

* Folder: `teh-software-engineering/module-2`
* File: `8-password-loop.py`
* Use a `while` loop.
* Ask for the password repeatedly.
* Stop the loop when the correct password is entered.
* Display an appropriate message for incorrect passwords.
* Make sure the loop can eventually end.
