# 2. Checking a Number

**Goal:** Use an `if` statement to make a decision.

Write a program that asks the user for a number.

If the number is greater than 0, print:

```text
The number is positive.
```

If it is not greater than 0, the program does not need to print anything.

**Example**

```text
Enter a number: 15

The number is positive.
```

## Requirements

* Folder: `teh-software-engineering/module-2`
* File: `2-checking-a-number.py`
* Ask the user for a number.
* Convert the input to a number.
* Use an `if` statement.
* Check whether the number is greater than 0.
