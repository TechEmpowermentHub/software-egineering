# Assessment

You will be assessed on your ability to:

* Identify syntax errors.
* Identify runtime errors.
* Identify logical errors.
* Read Python error messages and tracebacks.
* Reproduce a bug.
* Trace program execution.
* Inspect program state.
* Use debugging techniques.
* Use a debugger.
* Identify incorrect assumptions.
* Design useful test cases.
* Test boundary values.
* Test invalid inputs.
* Verify that a bug has been fixed.
* Perform regression testing.
* Explain the cause of a bug.
* Explain how a bug was fixed.
* Use Git to record a bug fix.

The final assessment will involve debugging a new program that the student has not seen before.

Students will be given a program containing multiple problems.

They must:

1. Run the program.
2. Identify the problems.
3. Reproduce the problems.
4. Explain the expected behavior.
5. Explain the actual behavior.
6. Identify the cause.
7. Fix the problems.
8. Test the program.
9. Perform regression testing.
10. Explain their debugging process.

The assessment will test whether students can investigate a problem systematically rather than simply recognize familiar errors.
