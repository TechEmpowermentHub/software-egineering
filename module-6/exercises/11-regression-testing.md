# 11 -  Regression Testing

**Goal:** Understand why existing functionality must be tested after making a change.

Take the Student Management System from the previous module.

Add the student search functionality.

Before changing the program, create a checklist of existing functionality:

```text
Add student
View students
Search student
Record score
Calculate result
Save students
Load students
Exit
```

After implementing the search feature, test all of them again.

## Requirements

Create: `11-regression-testing.md`

Document:

```text
Test
Expected Result
Actual Result
Status
```

for each feature.

## Questions

1. Why should existing functionality be tested after adding a new feature?
2. What is a regression bug?
3. Why might adding one feature break another feature?
