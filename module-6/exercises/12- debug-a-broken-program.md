# 12 - Debug a Broken Program

**Goal:** Combine debugging and testing skills to investigate a real program.

You are given a broken program that calculates the total cost of purchases.

The program is supposed to:

```text
Ask how many items the user wants to enter.
Ask for the price of each item.
Calculate the total.
Display the total.
```

The supplied program contains bugs.

Your job is to find them.

Do not immediately rewrite the program.

First:

```text
1. Run it.
2. Observe its behavior.
3. Reproduce each problem.
4. Record the expected behavior.
5. Record the actual behavior.
6. Identify the likely cause.
7. Fix one problem at a time.
8 Test after each fix.
```
