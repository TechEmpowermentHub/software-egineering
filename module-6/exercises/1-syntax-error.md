# 1 - Syntax Error

**Goal:** Identify and fix a syntax error.

The following program contains a syntax error:

```python
name = input("Enter your name: ")

if name:
    print("Hello", name)
else
    print("You did not enter a name.")
```

Run the program.

Read the error message.

Identify the problem and fix it.

## Requirements
* Folder: teh-software-engineering/module-6
* File: 1-syntax-error.py
* Run the broken program first.
* Read the traceback.
* Fix the syntax error.
* Run the corrected program.

Before fixing it, write down:

1. What error did Python report?
2. Which line caused the error?
3. What was wrong with that line?
