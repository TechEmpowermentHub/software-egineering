Exercises

The exercises progressively introduce the skills required to investigate, debug, test, and repair software.

```text
Syntax Errors
      ↓
Runtime Errors
      ↓
Reading Tracebacks
      ↓
Logical Errors
      ↓
Program Tracing
      ↓
Debugging with print()
      ↓
Using a Debugger
      ↓
Writing Test Cases
      ↓
Boundary Testing
      ↓
Invalid Input Testing
      ↓
Regression Testing
      ↓
Debugging a Real Program
      ↓
PROJECT
```

Complete the exercises in that order.

The goal is not simply to make a program work. You should understand what went wrong, why it went wrong, how you discovered the problem, and how you verified the fix.
