# 4 - Find the Logical Error

**Goal:** Understand that a program can run successfully and still be wrong.

The following program calculates the total cost:

```python
price = 2500
quantity = 4

total = price + quantity

print("Total:", total)
```

There is no syntax error.

There is no runtime error.

But the result is incorrect.

## Task

Identify the logical error.

Fix the program so that the total cost is correctly calculated.

## Questions
1. What did the program actually calculate?
2. What should it have calculated?
3. What caused the incorrect result?
4. How did you know the program was wrong?

## Requirements
* File: 4-logical-error.py
* Identify the bug.
* Fix it.
* Explain the difference between a logical error and a runtime error.
