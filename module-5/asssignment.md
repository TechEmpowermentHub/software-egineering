# Assignment

Complete all exercises independently and submit the Student Management System project.

Your submission should contain:

```text
module-5/

├── exercises/
│   ├── 1-create-repository/
│   ├── 2-stage-file/
│   ├── 3-first-commit/
│   ├── ...
│   └── 12-project-readme/
│
└── project/
    ├── student-management-system/
    │   ├── ...
    │   ├── README.md
    │   └── .gitignore
```

The Student Management System should be based on the program developed in the previous modules.

## Project Requirements

You must:

1. Create a Git repository for the project.

2. Make sure the existing project works before making changes.

3. Create a feature branch.

4. Add the student search feature.

5. Test the feature.

6. Commit the changes using meaningful commit messages.

7. Merge the feature into `main`.

8. Push the project to GitHub.

9. Update the project README.

10. Confirm that the final project works after the merge.

## Project README

Your project README should contain:

1. What the program does
2. Features
3. Requirements
4. How to run it
5. Example input
6. Example output
7. Project structure
8. How the student search feature works
9. The algorithm/pseudocode for the new feature
10. A brief explanation of the Git workflow used
11. How the feature branch was created and merged

## Git History

Your repository should contain meaningful commits.

Avoid commit messages such as:

```text
update
changes
final
test
stuff
```

Use messages that describe the change:

```text
Add student search feature
Add student search validation
Update README with search instructions
```
