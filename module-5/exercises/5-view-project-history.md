# 5 - View Project History

**Goal:** Understand how Git records the history of a project.

Using the repository from the previous exercises, run:

```text
git log
```

Then make another change to `hello.py`.

Commit the change.

Run:

```text
git log
```

again.


## Requirements

Your repository should now contain at least three commits.

For example:

* Add greeting message
* Update greeting
* Add initial hello program


## Questions

1. How many commits are in the repository?
2. What changed between the commits?
3. Why might a developer want to look at the history of a project?
