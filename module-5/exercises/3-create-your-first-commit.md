# 3 - Create Your First Commit

**Goal:** Record a change in the Git history.

Commit the staged file.

Use a meaningful commit message.

For example:

Add initial hello program

Then run:

```text
git status
```

and:

```text
git log
```

## Requirements

* Create a commit.
* Use a meaningful commit message.
* View the commit history.
* Confirm that the working directory is clean.


## Questions

1. What is a commit?
2. What information does a commit contain?
3. Why is Add initial hello program better than update?
