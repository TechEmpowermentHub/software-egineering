# 1 - Create a Git Repository

**Goal:** Understand what a Git repository is and initialize one.

Create a new folder called:

```text
git-practice
``

Inside the folder, create a Python file:

```text
hello.py

Add:

print("Hello, Git!")
```

Initialize the folder as a Git repository.

Use:

```text
git init
```

Then inspect the repository using:

```text
git status
```

* Folder: teh-software-engineering/module-5
