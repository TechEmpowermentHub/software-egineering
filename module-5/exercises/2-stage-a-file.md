# 2 - Stage a File

**Goal:** Understand the staging area.

Using the repository from Exercise 1, stage hello.py.

Use:

```text
git add hello.py
```

Then run:

```text
git status
```

Observe how the status changes.

## Questions

1. Was hello.py tracked before git add?
2. What changed after git add?
3. What does the staging area represent?
