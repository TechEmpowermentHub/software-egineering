# Exercises

The exercises progressively introduce the workflow developers use to manage software projects with Git.

```text
Version Control
      ↓
Git Repository
      ↓
Git Status
      ↓
Staging
      ↓
Commits
      ↓
Git History
      ↓
Reviewing Changes
      ↓
Branches
      ↓
Merging
      ↓
Merge Conflicts
      ↓
GitHub
      ↓
Project Documentation
      ↓
PROJECT
```

Complete the exercises in that order.

The goal is not simply to memorize Git commands. You should understand what Git is tracking, why a change is being recorded, and how developers use version control to safely change software.

By the end of the exercises, you should be able to create a repository, record changes, inspect project history, create branches, merge changes, resolve a simple conflict, and publish a project to GitHub.
