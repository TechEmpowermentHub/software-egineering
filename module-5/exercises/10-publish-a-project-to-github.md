# 10 - Publish a Project to GitHub

**Goal:** Understand the relationship between a local Git repository and a remote GitHub repository.

Create a repository on GitHub.

Connect your local repository to the GitHub repository.

Push the project.

Then make another local change, commit it, and push it again.

## Requirements

* Create a GitHub repository.
* Connect the local repository to GitHub.
* Push the project.
* Make another change.
* Commit the change.
* Push the new commit.
* Confirm that the change appears on GitHub.


## Questions
1. What is the difference between Git and GitHub?
2. What is a local repository?
3. What is a remote repository?
4. What does git push do?
