# 12 - Write a Project README

**Goal:** Learn how developers document software projects.

Create a `README.md` for your Git practice project.

The README should contain:

1. Project name
2. Description
3. Requirements
4. How to run the program
5. Example output
6. Project structure
7. Git workflow used

Example structure:

# Git Practice

## Description

...

## Requirements

...

## How to Run

...

## Example Output

...

## Project Structure

...

## Git Workflow

...

Commit the README.

Push the project to GitHub.

## Final Requirement

Your GitHub repository should now contain:

git-practice/

├── hello.py
├── README.md
└── .gitignore

and a meaningful Git history showing the development of the project.
