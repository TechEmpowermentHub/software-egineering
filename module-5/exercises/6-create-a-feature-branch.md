# 6 - Create a Feature Branch

**Goal:** Understand why developers use branches.

Create a new branch called:

```text
add-message
```

Switch to the branch.

Add another message to the program.

For example:

```python
print("Hello, Git and GitHub!")
print("This message was added on a feature branch.")
```

Commit the change.

## Requirements

* Create a feature branch.
* Switch to the branch.
* Modify the program.
* Test the program.
* Commit the change.
* View the available branches.


## Questions
1. What branch are you currently on?
2. Is the new change on main?
3. Why might a developer want to make a change on a separate branch?
