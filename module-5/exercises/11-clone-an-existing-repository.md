# 11 - Clone an Existing Repository

**Goal:** Understand how developers obtain an existing project.

Clone your GitHub repository into a different folder.

For example:

```text
git clone <repository-url>
```

Open the cloned project.

Inspect its Git history.

Run the Python program.

## Requirements

* Clone the repository.
* Open the cloned project.
* Run the program.
* Inspect its Git history.
* Make a small change.
* Commit it.
* Push the change to GitHub.


## Questions
1. What did git clone create?
2. Why would a developer clone a repository?
3. What is the difference between creating a repository with git init and obtaining one with git clone?
