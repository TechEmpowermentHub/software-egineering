# 4 - Make and Review a Change

**Goal:** Use Git to identify changes before committing them.

Modify `hello.py`.

Change:

```python
print("Hello, Git!")
```

to:

```python
print("Hello, Git and GitHub!")
```

Before staging the file, run:

```text
git status
```

Then:

```text
git diff
```

## Requirements

* Make a change to the program.
* Use git status.
* Use git diff.
* Identify exactly what changed.
* Stage the change.
* Commit it.

Use a meaningful commit message.

## Questions

1. What did git diff show?
2. Why is it useful to review changes before committing?
3. What would happen if you made an accidental change and committed it without reviewing it?
