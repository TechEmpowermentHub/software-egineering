# 8 - Merge a Feature

**Goal:** Combine a completed feature into the main project.

Switch to the main branch.

Merge the:

```text
add-message
```

branch.

Then run the program.

## Requirements

* Switch to main.
* Merge the feature branch.
* Run the program.
* Inspect the Git history.
* Confirm that the feature is now part of main.


## Questions
1. What does merging mean?
2. What happened to the feature after the merge?
3. Can the feature branch still exist after the merge?
