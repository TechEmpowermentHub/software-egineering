# Assessment

You will be assessed on your ability to:

* Explain what version control is and why it is useful.
* Explain the difference between a working directory, staging area, and repository.
* Create a Git repository.
* Track changes.
* Stage files.
* Create meaningful commits.
* Read and interpret Git history.
* Review changes before committing them.
* Create and use branches.
* Merge branches.
* Explain why merge conflicts occur.
* Resolve a simple merge conflict.
* Push a project to GitHub.
* Clone an existing repository.
* Write useful project documentation.
* Follow a basic feature-development workflow.
* Explain the changes made to a software project.

The final assessment will involve taking an existing small program and making a new change using Git.

Students will not be told exactly which Git commands to use for every step.

The assessment will test whether they understand **why each step is required and how version control fits into the software development process**, rather than whether they can simply reproduce the exercise instructions.
